# Amalfi Citrus Club — Asset Prompt Library

Use these briefs to generate the exact source artwork for Collection 01. Every finished asset must be saved separately before it is used in mockups or boards.

## Shared Art Direction

- Original luxury coastal resort aesthetic
- Soft watercolor and gouache texture with refined hand-drawn outlines
- Sun-washed pastel palette: Amalfi blue, butter yellow, coral, cream, leafy green
- Feminine, editorial, playful, polished, and commercially usable
- No copied logos, trademarks, branded scooters, copyrighted characters, or identifiable third-party artwork
- Keep line weight, paint texture, saturation, and motif scale consistent across the collection

## 01 Hero Seamless Print

Create an original seamless repeating pattern for Tide & Bloom's Amalfi Citrus Club. Include hand-painted lemons, sliced oranges, blue-and-cream Italian tile fragments, coral bows, tiny coastal postage-stamp shapes, sailboats, and leafy branches. Use airy spacing with a balanced tossed layout and subtle watercolor texture. The repeat must tile perfectly on all edges. Avoid text and recognizable trademarks.

**Output:** 6000 × 6000 px square tile, 300 DPI, high-resolution PNG and layered source file.

## 02 Secondary Seamless Print

Create a seamless watercolor pattern featuring oversized lemons with delicate leaves, small coral blossoms, cream negative space, and tiny Amalfi-blue dots. Use fewer motifs than the hero print and a clean premium resortwear composition.

**Output:** 6000 × 6000 px, 300 DPI, seamless PNG.

## 03 Coordinate Print

Create a small-scale seamless coordinate pattern using alternating coral bows, tiny lemons, miniature blue stars, and cream spacing. Keep it light enough to pair with the hero pattern on children's swimwear and pajama trims.

**Output:** 4000 × 4000 px, 300 DPI, seamless PNG.

## 04 Stripe

Create a seamless hand-painted vertical stripe using Amalfi blue and cream with occasional thin butter-yellow pinstripes. Slight watercolor variation is allowed, but the repeat must remain clean and production friendly.

**Output:** 4000 × 4000 px, 300 DPI, seamless PNG.

## 05 Mini Print

Create a dense but delicate micro-print of tiny lemons, coral dots, blue petals, and miniature leaves on cream. Designed for lining, cuffs, baby products, and small accessories.

**Output:** 4000 × 4000 px, 300 DPI, seamless PNG.

## 06 Texture Print

Create a subtle seamless cream linen-and-watercolor wash texture with barely visible butter-yellow and pale blue variation. No obvious motifs. It should function as a quiet background coordinate.

**Output:** 4000 × 4000 px, 300 DPI, seamless PNG.

## Collection Logo

Create an original transparent placement graphic reading “Amalfi Citrus Club” with elegant coastal serif lettering, a small hand-painted lemon branch, a coral bow, and a tiny wave underline. Do not imitate an existing fashion brand logo.

**Output:** transparent PNG, 4500 × 5400 px canvas, 300 DPI, plus editable vector or layered source.

## Back Graphic

Create a large original back graphic for a relaxed resort tee. Include the phrase “Amalfi Citrus Club,” a hand-painted Italian-coast inspired seaside scene, lemons, a sailboat, coral florals, and the Tide & Bloom name in small type. Keep the design screen-print friendly and isolated on transparency.

**Output:** transparent PNG, 4500 × 5400 px, 300 DPI.

## Pocket Graphic

Create a small lemon branch and coral bow emblem with the initials “T & B.” Keep it simple enough for embroidery or a small chest print.

**Output:** transparent PNG and simplified vector version.

## Badge Logo

Create a circular Amalfi Citrus Club badge with a lemon, wave, small sailboat, and “Tide & Bloom.” Use clean linework and limited colors so it can be used for hats, patches, labels, and stickers.

**Output:** transparent PNG and vector source.

## Sticker Pack

Create eight separate original stickers: lemon cluster, coral bow, sailboat, blue tile heart, citrus postage stamp, tiny coastal scooter silhouette with no brand marks, “Sunny Days,” and Amalfi Citrus Club badge.

**Output:** eight individual transparent PNG files plus one sticker-sheet preview.

## Embroidery Patch

Create a simplified embroidered-style lemon and wave crest with no more than six thread colors. Use bold clean shapes and avoid tiny details.

**Output:** transparent PNG reference and embroidery-ready simplified vector.

## Quality Gate

Before approval, verify:

- The seamless edges match with no visible seams
- The file dimensions and DPI are correct
- Transparent assets contain no white background
- Text is spelled correctly
- Motifs are original and legally safe
- Colors match the collection palette
- The exact approved source asset is preserved before mockup creation
