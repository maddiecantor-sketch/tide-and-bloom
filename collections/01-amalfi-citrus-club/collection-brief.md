# Collection 01 — Amalfi Citrus Club

## Role

Pilot collection for proving the complete Tide & Bloom workflow from concept through production artwork, products, mockups, storefront listings, and launch content.

## Story

A sun-washed Italian coastal collection inspired by lemon groves, hand-painted blue tiles, vintage postcards, scooters, sailboats, striped umbrellas, and slow afternoons by the sea.

## Palette

- Amalfi Blue — `#C9DCE8`
- Butter Yellow — `#F0D98A`
- Coral — `#D98868`
- Cream — `#FBF8F3`
- Optional accent: Deep Mediterranean Blue — `#315D73`

## Motifs

- Lemons and lemon branches

- Italian postage stamps

- Striped umbrellas

## Required Pattern Set

1. Hero seamless print — dense storytelling layout
2. Secondary seamless print — simpler citrus and bow repeat
3. Coordinate print — blue tile or postcard-inspired repeat
4. Stripe — hand-painted Mediterranean stripe
5. Mini print — tiny lemons, flowers, or stamps
6. Texture — washed linen or watercolor paper texture

## Required Graphics

- Front placement graphic
- Back placement graphic
- Pocket graphic
- Sleeve graphic
- Badge logo
- Collection wordmark
- Sticker pack
- Embroidery patch artwork

## Production Specifications

### Seamless Patterns

- 6000 × 6000 px for hero and secondary patterns
- 4000 × 4000 px minimum for coordinate, mini, stripe, and texture
- 300 DPI metadata
- Seamless repeat verified on all four edges
- RGB master file; export vendor-specific color versions as required
- Preserve editable layered source files

### Placement Graphics

- Transparent PNG
- 4500 × 5400 px minimum for apparel artwork
- 300 DPI metadata
- No unnecessary transparent padding
- Keep text and fine lines readable at print size
