# Tide & Bloom Production QA Checklist

Use this checklist before approving any print, placement graphic, mockup, or storefront image.

## Source Artwork

- [ ] Exact source file is saved separately from any moodboard or mockup
- [ ] Filename matches the collection asset manifest
- [ ] Dimensions match the required pixel size
- [ ] Resolution metadata is 300 DPI where required
- [ ] Transparent artwork has a truly transparent background
- [ ] No accidental white halo or cropped edge
- [ ] Colors match the approved collection palette
- [ ] Line weight and watercolor treatment match the brand system
- [ ] Text is spelled correctly and remains readable at print size
- [ ] Artwork is original and free of protected trademarks or copied brand marks

## Seamless Patterns

- [ ] Tile repeats perfectly on all four edges
- [ ] No visible seams at 2x2 and 4x4 repeat previews
- [ ] Motifs do not create accidental lines, gaps, or clusters
- [ ] Scale works on both swimwear and larger home products
- [ ] Pattern preview is tested at actual product dimensions

## Placement Graphics

- [ ] Transparent PNG exported at the exact required dimensions
- [ ] Important details stay inside the vendor safe area
- [ ] Thin details are thick enough to print cleanly
- [ ] Small text remains readable
- [ ] Graphic works on light and dark garment colors

## Product Mockups

- [ ] Mockup uses the exact approved source artwork
- [ ] Pattern scale matches the product asset map
- [ ] Print placement is realistic and follows garment seams
- [ ] No warped logos, broken straps, extra limbs, or distorted hands
- [ ] Product color is consistent across all views
- [ ] Front, back, detail, flat-lay, and lifestyle images are included where required
- [ ] Lifestyle image does not misrepresent garment construction or fit

## Storefront

- [ ] Product title, price, and description match the catalog data
- [ ] Every image has descriptive alt text
- [ ] Mobile image crop keeps the product visible
- [ ] Buttons and links work
- [ ] No placeholder imagery remains before launch
- [ ] Shipping, returns, sizing, and care information are present

## Final Approval

Record the approver, date, vendor template version, and final filenames before changing an asset status to `approved`.
