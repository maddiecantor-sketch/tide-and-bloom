# Tide & Bloom

Luxury coastal print-on-demand and ecommerce brand operating system.

## Brand Direction

Tide & Bloom blends modern resortwear, feminine coastal design, family matching collections, swimwear, apparel, accessories, and home goods. The visual system is editorial, sun-washed, bohemian, and premium.

**Tagline:** Made for Sunny Days & Salty Waves

## Project Areas

- `brand/` — logo, color, typography, voice, and design rules
- `collections/` — master data for all 12 collections
- `production/` — print, graphic, mockup, and POD specifications
- `marketing/` — launch content, UGC ads, social, and email workflows
- `storefront/` — ecommerce website and Shopify-ready frontend work
- `docs/` — roadmap, decisions, and operating documentation

## Initial Build Order

1. Finalize brand system
2. Build Collection 01: Amalfi Citrus Club end to end
3. Create production-ready artwork specifications
4. Build the luxury storefront foundation
5. Create product and pricing data
6. Produce mockups and launch content
7. Repeat the system across the remaining collections
